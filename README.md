 # Qalqon Security Console

 Uzbek-language cybersecurity dashboard demo built with React and Vite. It includes a security overview, simulated file analysis, a scripted AI chat, security lessons, and profile settings.

 ## Run locally

 ```sh
 npm install
 npm run dev
 ```

 ## Checks

 ```sh
 npm run lint
 npm run build
 ```

 ## Demo scope

 This project is a frontend prototype. File scan results and AI responses are simulated in the browser; no file is uploaded and no real antivirus, AI, identity, or monitoring service is connected. Production use requires a secured backend and integrations with trusted security services.
